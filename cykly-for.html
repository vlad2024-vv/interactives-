Цикл for з параметром

Дізнайся, як змусити програму повторювати дії, як працює range(), як стежити за змінною циклу та як розв’язувати задачі з циклами. Є пояснення, приклади, візуалізація й практика прямо в браузері.

🧭 План уроку

1. ТеоріяНавіщо цикл, як він записується, три форми range()
2. ПрикладиШість готових програм із результатом і поясненням
3. ПрактикаТренажер, вправи «що виведе програма» й власні програми

1. Навіщо потрібен цикл

Щоб вивести числа від 1 до 5, без циклу довелося б написати п’ять команд:

print(1)
print(2)
print(3)
print(4)
print(5)

А якщо чисел тисяча? Цикл дозволяє записати команди один раз, а виконати їх стільки разів, скільки потрібно. Цикл for застосовують, коли заздалегідь відомо, скільки разів щось повторювати.

2. Як записується цикл for

for i in range(1, 6):
    print(i)
ЧастинаЩо означає
forпочаток циклу
iзмінна циклу (параметр): на кожному повторенні отримує наступне значення. Ім’я може бути будь-яким: i, k, day
range(1, 6)які значення пройде змінна: 1, 2, 3, 4, 5
:двокрапка в кінці рядка обов’язкова
відступ (4 пробіли)усе, що з відступом, входить у тіло циклу і повторюється
⚠ Останнє число в range не входить у діапазон. range(1, 6) дає 1, 2, 3, 4, 5, а число 6 уже ні.
💡 Кожне виконання тіла циклу називають ітерацією (повторенням). У range(1, 6) їх п’ять.

3. Три форми range()

ЗаписЩо даєПриклад
range(n)від 0 до n − 1, рівно n значеньrange(4) → 0 1 2 3
range(a, b)від a до b − 1range(2, 6) → 2 3 4 5
range(a, b, k)від a до b − 1 з кроком krange(1, 10, 3) → 1 4 7
range(a, b, −k)у зворотному порядку (a більше за b)range(5, 0, -1) → 5 4 3 2 1

🧪 Дослідник range

Змінюй числа й дивись, що отримає змінна циклу. Спробуй старт 10, кінець 0, крок −2.

4. Покроковий перегляд циклу

Подивись, як змінюються значення під час роботи програми. Обери N і натискай «Наступний крок».

total = 0
for i in range(1, N + 1):
    total = total + i
print(total)
Ітераціяitotal булоtotal стало
Початково total = 0.

5. Приклади програм

Відкривай приклади, читай код і результат. Спробуй передбачити відповідь, перш ніж дивитися.

1. Повторення дії: range(n) 
for i in range(3):
    print("Привіт!")
Привіт! Привіт! Привіт!

Змінну i тут не використовуємо, потрібна лише кількість повторень.

2. Зворотний відлік: від’ємний крок 
for i in range(5, 0, -1):
    print(i)
print("Старт!")
5 4 3 2 1 Старт!

Рядок print("Старт!") без відступу стоїть після циклу й виконується один раз.

3. Таблиця множення 
for k in range(1, 4):
    print(7, "*", k, "=", 7 * k)
7 * 1 = 7 7 * 2 = 14 7 * 3 = 21

Змінна циклу k використовується у формулі.

4. Сума чисел (накопичення) 
total = 0
for i in range(1, 6):
    total = total + i
print(total)
15

Спочатку створюємо total = 0, потім у циклі додаємо кожне число: 1 + 2 + 3 + 4 + 5.

5. Підрахунок кількості: if усередині for 
count = 0
for i in range(1, 11):
    if i % 2 == 0:
        count = count + 1
print(count)
5

Лічильник збільшується лише для парних чисел: 2, 4, 6, 8, 10.

6. Сума парних чисел: крок 2 
total = 0
for i in range(2, 11, 2):
    total = total + i
print(total)
30

Крок 2 одразу дає парні числа: 2 + 4 + 6 + 8 + 10 = 30, перевірка if не потрібна.
