📚 Бібліотека прикладів Python

Оберіть категорію, а потім потрібний приклад. Код з'явиться в редакторі після натискання кнопки.

💻 Редактор Python

Швидкі клавіші: Ctrl + Enter — запустити програму; Ctrl + Пробіл — відкрити підказки коду; Tab або Enter — вставити вибрану підказку. Почніть вводити команду або назву змінної — редактор запропонує варіанти.

⌨ Вхідні дані

Якщо програма використовує input(), введіть потрібні значення тут. Кожне значення має бути з нового рядка. Після запуску поле очищується автоматично. Для швидкого очищення натисніть Ctrl + Backspace.
