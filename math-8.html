Від умови до програми

Пригадаємо основи програмування, розберемося, як працює програма, і навчимося поступово переходити від умови задачі до її розв'язання.

1. Пригадуємо основи

Перш ніж писати програму, пригадаємо кілька понять, з якими ви вже знайомилися раніше.

Визначення Інформатика — це наука про інформацію, способи її отримання, зберігання, опрацювання та передавання за допомогою комп'ютерів та інших пристроїв.
Визначення Алгоритм — це скінченна послідовність чітких команд, виконання яких приводить до розв'язання задачі.

Алгоритми трапляються не лише в програмуванні. Наприклад, інструкція з користування пристроєм, рецепт страви або порядок дій під час входу до електронної пошти — це приклади алгоритмів.

Приклад: алгоритм приготування чаю
  1. Налити воду в чайник.
  2. Закип'ятити воду.
  3. Покласти чай у чашку.
  4. Залити чай гарячою водою.
  5. Дочекатися, поки чай завариться.
Визначення Виконавець алгоритму — це людина, комп'ютер або інший пристрій, який виконує команди алгоритму.
Визначення Команда — це вказівка виконавцю виконати певну дію.

2. Пригадуємо математичні дії

Комп'ютер може виконувати обчислення. У Python для цього використовують спеціальні знаки — оператори.

Основні арифметичні оператори Python
  • + — додавання.
  • - — віднімання.
  • * — множення.
  • / — ділення.
  • // — цілочисельне ділення.
  • % — остача від ділення.
  • ** — піднесення до степеня.
Запам'ятай Оператор — це спеціальний знак або символ, який указує комп'ютеру, яку дію потрібно виконати.

Приклади обчислень

print(8 + 4)    # 12
print(8 - 4)    # 4
print(8 * 4)    # 32
print(8 / 4)    # 2.0
print(9 // 2)   # 4
print(9 % 2)    # 1
print(2 ** 3)   # 8
Зверніть увагу: у Python для множення використовується символ *, а не знак ×. Для ділення використовується /.

Порядок виконання дій

Як і в математиці, спочатку виконуються дії в дужках, потім множення та ділення, а після цього додавання і віднімання. 

result = 5 + 3 * 2
print(result)

Результат буде 11, оскільки спочатку виконується множення.

3. Що таке змінна?

У програмі часто потрібно зберігати числа, слова та інші значення. Для цього використовують змінні.

Визначення Змінна — це іменована ділянка пам'яті, у якій зберігається певне значення.

Змінній можна надати ім'я та записати в неї значення. Для цього використовують знак присвоювання =. 

age = 14
name = "Олена"
price = 25.5

У цьому прикладі створено три змінні: age, name та price.

Приклад використання змінних
a = 10
b = 5

c = a + b

print(c)
Результат виконання програми: 15
Важливо: знак = у програмуванні означає присвоювання значення, а не перевірку рівності двох чисел.

4. Якими бувають дані?

Комп'ютер працює з різними видами даних. У Python кожне значення має свій тип.

Визначення Тип даних — це характеристика значення, яка визначає, які дані зберігаються та які операції з ними можна виконувати.
Основні типи даних Python
  • int — цілі числа: 5, 12, -8.
  • float — дійсні числа: 3.14, 2.5, -0.7.
  • str — текст: "Привіт", "Python".
  • bool — логічні значення: True або False.

Приклад

age = 14
height = 1.65
name = "Андрій"
is_student = True

print(age)
print(height)
print(name)
print(is_student)

Зверніть увагу: текст записують у лапках, а числа — без лапок.

5. Введення та виведення даних

Програма може отримувати інформацію від користувача та показувати результат своєї роботи.

Запам'ятай Введення даних — це передавання інформації програмі від користувача або іншого джерела.
Запам'ятай Виведення даних — це показ результатів роботи програми користувачеві.

Команда input()

Для введення даних у Python використовують команду input(). 

name = input("Як тебе звати? ")

print("Привіт,", name)

Команда print()

Для виведення тексту, чисел та результатів обчислень використовують команду print(). 

print("Вітаю!")
print(10 + 5)
Команда input() за замовчуванням отримує введене значення як текст. Якщо потрібно виконувати обчислення з числами, текст потрібно перетворити на числовий тип.

6. Як перетворити текст на число?

Коли користувач вводить число за допомогою input(), Python сприймає його як текст. Тому перед обчисленнями часто потрібно перетворити введене значення.

Запам'ятай Перетворення типів — це зміна типу даних з одного на інший.
Два способи перетворення

int() — перетворює значення на ціле число.

age = int(input("Введіть вік: "))

float() — перетворює значення на дійсне число.

price = float(input("Введіть ціну: "))

Приклад програми

a = int(input("Введіть перше число: "))
b = int(input("Введіть друге число: "))

s = a + b

print("Сума:", s)

Якщо ввести 7 та 5, програма виведе 12.

7. Від умови до розв'язання

Тепер пригадаємо, як правильно підходити до розв'язування задач. Не потрібно відразу писати програму. Спочатку розберімося з умовою.

Визначення Вхідні дані — це інформація, яку ми отримуємо для розв'язання задачі.
Визначення Вихідні дані — це результат, який потрібно отримати після виконання задачі.
Розглянемо задачу

У магазині купили 3 кг яблук. Один кілограм коштує 35 грн. Скільки потрібно заплатити?

Відомо:

  • Кількість яблук — 3 кг.
  • Ціна одного кілограма — 35 грн.

Потрібно знайти: загальну вартість.

Математична дія:

3 × 35 = 105

Відповідь: потрібно заплатити 105 грн.

Записуємо розв'язання мовою Python

weight = 3
price = 35

total = weight * price

print("До сплати:", total, "грн")

Програма зберігає відомі значення у змінних, обчислює вартість і виводить результат.

8. Як побудувати алгоритм?

Під час розв'язування задач важливо правильно визначити послідовність дій.

Запам'ятай Послідовний алгоритм — це алгоритм, у якому команди виконуються одна за одною в установленому порядку.
Приклад: обчислення площі прямокутника
  1. Отримати довжину прямокутника.
  2. Отримати ширину прямокутника.
  3. Помножити довжину на ширину.
  4. Вивести площу.

Саме таку послідовність потрібно буде використати під час написання програми.

9. Перевір, що ти пригадав

Обери правильну відповідь. Після кожного запитання з'явиться пояснення.

Правильних відповідей: 0 із 8

10. Побудуй алгоритм

Розташуй команди у правильному порядку. Потрібно скласти алгоритм обчислення суми двох чисел.

Завдання Переміщуй команди за допомогою стрілок, щоб отримати правильну послідовність.

11. Склади програму

Частини програми Python переплуталися. Розташуй їх у правильному порядку, щоб програма обчислювала суму двох чисел.
