Випадкові величини в Python

Модуль random, випадковий вибір і використання розгалужень у програмах

Вступ Модуль random randint() choice() Розгалуження Практика Перевірка знань

1. Що таке випадкові величини?

Уявіть комп'ютерну гру. На початку кожного раунду програма випадково визначає кількість балів, обирає суперника або вирішує, яка подія відбудеться.

Або інша ситуація: ви створюєте програму для жеребкування. Вона повинна випадково обрати одного учасника зі списку.

Випадкове значення — це значення, яке програма отримує за допомогою спеціального алгоритму випадкового вибору. Наперед ми не знаємо, яке саме значення буде отримано під час наступного запуску.
🎲 Ігри

Кидання кубика, випадкові бали, поява перешкод.

🎯 Жеребкування

Вибір переможця або учасника.

🧠 Навчання

Створення випадкових математичних завдань.

🌦️ Моделювання

Імітація різних подій і ситуацій.

Важливо: комп'ютер не «вгадує» числа. Модуль random використовує алгоритми генерації псевдовипадкових значень. Для наших навчальних програм цього цілком достатньо.

2. Підключаємо модуль random

У Python є готові модулі — набори команд, які розширюють можливості мови програмування.

Для роботи з випадковими значеннями використовують модуль random. 

import random
import random — команда, яка підключає модуль random до нашої програми. Після цього ми можемо використовувати його команди.

Наприклад:

import random

number = random.randint(1, 10)

print(number)

Програма створює змінну number і записує в неї випадкове ціле число від 1 до 10.

Зверніть увагу: якщо ви використовуєте команду random.randint(), перед нею потрібно написати import random.

3. Команда random.randint()

Найчастіше для отримання випадкового цілого числа використовують команду random.randint(). 

random.randint(a, b)
random.randint(a, b) повертає випадкове ціле число від a до b включно.

Розглянемо приклади

import random

number = random.randint(1, 6)
print(number)

Програма імітує кидання звичайного грального кубика. Можливі результати: 1, 2, 3, 4, 5 або 6. 

import random

temperature = random.randint(-5, 10)
print(temperature)

Тут програма отримує випадкову температуру від -5 до 10 градусів. Від'ємні числа також можна використовувати.

Важливо запам'ятати!
У команді randint обидві межі включаються в діапазон. Наприклад, random.randint(1, 5) може повернути і число 1, і число 5.

Приклад: випадкові бали

import random

points = random.randint(1, 12)

Під час кожного запуску програма може показати іншу кількість балів від 1 до 12.

4. Команда random.choice()

Не завжди потрібно отримувати число. Іноді програма повинна випадково обрати один елемент із кількох запропонованих. 

random.choice(послідовність)
random.choice() випадково обирає один елемент із заданої послідовності, наприклад зі списку або рядка.

Приклад 1. Випадковий вибір тварини

import random

animals = ["кіт", "пес", "папуга", "хом'як"]

animal = random.choice(animals)

print("Сьогодні обрано:", animal)

Спочатку створюється список тварин. Потім команда random.choice(animals) обирає одну з них.

Приклад 2. Випадковий вибір із рядка

import random

letter = random.choice("ПРОГРАМУВАННЯ")

print(letter)

У цьому випадку програма випадково обирає один символ із рядка.

Спробуйте самостійно

Програма випадково обирає одну з чотирьох тварин.

Кого обере програма?

Уявімо, що програма визначає, чим зайнятися після уроків.

Натисніть кнопку.
Не плутайте команди:
random.randint(1, 10) — створює випадкове ціле число.
random.choice(spysok) — обирає випадковий елемент із послідовності.

5. Поєднуємо random і розгалуження

А тепер найцікавіше. Випадкове значення можна використати для прийняття рішення в програмі.

Пригадаємо: розгалуження дає змогу програмі виконувати різні команди залежно від умови. 

if умова:
    команда
elif інша_умова:
    команда
else:
    команда

Приклад 1. Велике чи мале число?

import random

number = random.randint(1, 10)

print("Випало число:", number)

if number > 5:
    print("Це велике число")
elif number < 5:
    print("Це мале число")
else:
    print("Випало число 5")

Як працює ця програма?

  1. Програма отримує випадкове число від 1 до 10.
  2. Перевіряє, чи більше воно за 5.
  3. Якщо ні — перевіряє, чи менше воно за 5.
  4. Якщо обидві умови хибні, виконується блок else.

Приклад 2. Випадковий результат змагання

import random

points = random.randint(0, 100)

print("Результат учасника:", points)

if points >= 90:
    print("Відмінний результат!")
elif points >= 60:
    print("Хороший результат!")
else:
    print("Потрібно потренуватися.")
Тут важливо зрозуміти: випадкове число саме по собі нічого не вирішує. Програма отримує його, а потім за допомогою розгалуження визначає, які команди виконати.

Інтерактивна демонстрація

Програма випадково визначає кількість балів від 0 до 100, а потім оцінює результат.

Очікуємо на результат...

Приклад 3. Випадкове число — парне чи непарне?

import random

number = random.randint(1, 20)

print("Отримали число:", number)

if number % 2 == 0:
    print("Число парне")
else:
    print("Число непарне")

Оператор % знаходить остачу від ділення. Якщо остача від ділення на 2 дорівнює нулю, число парне.

6. Практичні завдання

Спробуйте самостійно розібратися з умовами та передбачити, що робитиме програма.

Завдання 1. Випадковий кубик

Створіть програму, яка імітує кидання кубика. Отримайте випадкове число від 1 до 6. Якщо випало 6 — виведіть повідомлення «Вітаємо! Максимальний результат!». В інших випадках виведіть «Спробуйте ще раз». 

import random

number = random.randint(1, 6)

print("Випало:", number)

if number == 6:
    print("Вітаємо! Максимальний результат!")
else:
    print("Спробуйте ще раз")
Завдання 2. Вибір подарунка

Створіть список із чотирьох подарунків. За допомогою random.choice() випадково оберіть один подарунок і виведіть його на екран. 

import random

gifts = ["книга", "навушники", "м'яч", "настільна гра"]

gift = random.choice(gifts)

print("Ваш подарунок:", gift)
Завдання 3. Перевірка числа

Програма отримує випадкове число від 1 до 30. Якщо число менше 10 — виведіть «Мале число». Якщо число від 10 до 20 включно — «Середнє число». Якщо число більше 20 — «Велике число». 

import random

number = random.randint(1, 30)

print("Число:", number)

if number < 10:
    print("Мале число")
elif number <= 20:
    print("Середнє число")
else:
    print("Велике число")
Завдання 4. Мінігра «Вгадай число»

Програма випадково обирає число від 1 до 5. Користувач вводить своє число. Якщо числа однакові — виведіть «Ви вгадали!». Інакше — «Не вгадали. Спробуйте ще раз». 

import random

secret = random.randint(1, 5)

user_number = int(input("Введіть число від 1 до 5: "))

print("Загадане число:", secret)

if user_number == secret:
    print("Ви вгадали!")
else:
    print("Не вгадали. Спробуйте ще раз")
Завдання 5. Випадкова погода

Створіть програму, яка випадково обирає температуру від -10 до 30 градусів. Якщо температура нижча за 0 — виведіть «Мороз». Якщо від 0 до 20 включно — «Прохолодно». Якщо вища за 20 — «Тепло». 

import random

temperature = random.randint(-10, 30)

print("Температура:", temperature)

if temperature < 0:
    print("Мороз")
elif temperature <= 20:
    print("Прохолодно")
else:
    print("Тепло")

8. Підсумуємо

import random

Підключає модуль випадкових величин.

random.randint(a, b)

Повертає випадкове ціле число від a до b включно.

random.choice()

Випадково обирає один елемент із послідовності.

random + if

Дає змогу створювати програми, які приймають рішення залежно від випадкового значення.

Головна думка уроку: випадкові значення роблять програми різноманітнішими, а розгалуження дають змогу програмі реагувати на отримані значення. Саме так створюють прості ігри, симуляції та навчальні програми.
